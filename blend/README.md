# Realized Blend

`realized-blend` contains the dependency-light domain contracts for contextual,
operator-centered work in Realized.

It owns values and pure rules for contexts, actors, operators, sessions, worlds,
workflow plans and runs, history, coordination, and execution observations.
It does not own workstation presentation, governance decisions, event
transport, concrete skill execution, host effects, or application composition.

The package follows the model described in the repository's `BLEND.md` while
remaining usable without a workstation shell.
