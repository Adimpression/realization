# Agentic

### 1. Precise

**Definition.** Participation is a 2-category over CategoryOfBoundaries: objects are boundaries; morphisms are boundary maps, closed under ⊗ (wire), ◁ (iterate) and ∘ (wrap); 2-morphisms are re-wirings. Participants are step rules inhabiting boundaries.

1. *Boundary.* For any set X, Boundary(X) = Σ_{Outgoing ∈ OutgoingSet} X^{IncomingSet(Outgoing)}: put out one Outgoing, then await one Incoming ∈ IncomingSet(Outgoing). OutgoingSet = everything that may go out across the boundary; IncomingSet(Outgoing) = everything that may come back in reply to that Outgoing.
2. *Step.* Step = one Outgoing out, then one Incoming ∈ IncomingSet(Outgoing) in, at one boundary. The sole generator.
3. *BoundaryMap.* A morphism BoundaryMap : Boundary₁ → Boundary₂ is a pair ForwardMap : OutgoingSet₁ → OutgoingSet₂ and BackwardMap : (Outgoing, Incoming ∈ IncomingSet₂(ForwardMap(Outgoing))) ↦ Incoming′ ∈ IncomingSet₁(Outgoing). Outgoings go forward; incomings come back.
4. *Participant.* Participant = (StateSpace, StepRule : StateSpace → Boundary(StateSpace)): from each state, an outgoing to put out and, for each incoming received, a next state. Unpacked: StateSpace = Knowledge (facts, procedures, conditions). ForwardMap : StateSpace → OutgoingSet = Regulation, choosing among {Act, Abstain, Escalate, Warn}, realized as Action (target Environment), Delegation (target AnotherAgent) or Utterance (target Agent or Human). BackwardMap : (State, Incoming) ↦ NextState = Comprehension. Retrieval = a Step whose counterparty is a Store (a participant that holds knowledge). Conversation = a Wire between two participants, part of neither. Environment = the participant every Action targets.
5. *Operators.* Wire : Boundary₁ ⊗ … ⊗ Boundaryₙ → OuterBoundary, where ⊗ places boundaries side by side; the map routes one box's outgoings to another's incomings, and Feedback = a wire whose target is a sibling box. Iterate = Boundary ◁ Boundary ◁ … ◁ Boundary = Boundary^{◁ NumberOfSteps}, where ◁ means "do the first, then the next" with state carried; Transcript = the unrolled iterate; Convergence = (NextState = State), a fixed point. Wrap : Boundary → Boundary, an endomorphism placed between a participant and its counterparty, which may pass, alter, deny, escalate or record each step; from outside, the wrapped boundary is the same boundary.
6. *2-morphisms.* A 2-morphism = a morphism between morphisms: a change to a Wire or a Wrap rather than to the world — Calibration, Promotion, Rollback, Rotation. Delegation = the morphism whose effect is a 2-morphism, because it creates a new Wire.
7. *Classes.* Classes = {Environment, Tool, Agent, Human}. Datasheet(Participant) = (Latency, Bandwidth, ErrorRate, DecayUnderLoadOrPersuasion), measured at the boundary. PremiseNoPrivilegedAccess: a participant is known only through its boundary, so classes differ only by Datasheet. Slot = a place in a wiring that a participant fills. PremiseNoIntrinsicAuthority: Authority is a property of a Slot (the last stage of a review chain), never of its occupant.
8. *Governance.* May = Wrap ∘ Regulation (interior first, then exterior). TheLaw: Regulation = f(Wrap) — the regulation wired to a consequential wrap changes toward passing it. Corollary: boundaries compose exactly; participants do not.
9. *Laws.* Interchange: (Boundary₁ ◁ Boundary₂) ⊗ (Boundary₃ ◁ Boundary₄) → (Boundary₁ ⊗ Boundary₃) ◁ (Boundary₂ ⊗ Boundary₄) — a dialogue is one object whether taken turn by turn or whole. Stacking: Wrap₁ ∘ Wrap₂ is a Wrap; the endomorphisms of a boundary form a monoid (∘ associative, id = the do-nothing wrap). Identity: id_Boundary exists — the idle step; waiting and refusing are participations. FixedPoint: at Convergence, Action = id_Environment (Idempotence).

### 2. Descriptive

**What this is.** One way to describe everything that can take part in work when humans, AI agents, tools and the world act together. The claim is that all of it reduces to a single picture: things that occupy boundaries, exchanging what goes out and what comes back, combined by three operations and adjusted at one higher level.

**Boundaries.** A boundary is a place where something can be put out and something can come back. What can be put out is an *outgoing*: a command sent to a server, a sentence said in a chat, a plan submitted for approval, a query sent to a database. What can come back in reply to a given outgoing is an *incoming*: the server's result, the reply in the chat, an approve-or-reject verdict, the database's answer. A boundary is fully described by listing its outgoings and, for each outgoing, the incomings it allows back. A shell is a boundary (outgoings: commands; incomings: output and exit codes). A chat is a boundary (outgoings: utterances; incomings: replies). The place where an AI submits a proposed change and receives a verdict is a boundary (outgoings: proposals; incomings: accept, reject, escalate).

**Steps.** A step is one exchange at one boundary: one outgoing out, one incoming back. Everything described here is built from steps and nothing else. Two things follow. Sensing is not a separate ability: an observation is simply the incoming half of a step whose counterparty is the world. And whatever crosses a boundary — a message, a plan, a code change, a verdict — is an outgoing; evidence attached to a decision is an outgoing bound to the step that produced it.

**Participants.** A participant is anything that occupies a boundary: a human, an AI agent, a tool, a database, the physical world itself. From outside, a participant is nothing but what crosses its boundary; there is no other way to know it. From inside, a participant has three parts.

- *Knowledge* is its state: the facts it holds, the procedures it can run, the conditions under which it applies them.
- *Regulation* is the rule that, given the current state, decides what to put out: act, hold back, ask for help, or flag doubt. Self-control, abstention, escalation and confidence labels all live here.
- *Two maps* join inside to outside. Inward, *comprehension* takes an incoming that has arrived and turns it into a change of state. Outward, the chosen outgoing leaves as an *action* (aimed at the world), a *delegation* (aimed at another agent) or an *utterance* (aimed at an agent or a human).

Three everyday terms sit in particular places. *Retrieval* looks inward but is really a step aimed at a store: a request goes out to a knowledge store and an incoming comes back; it is an action whose counterparty happens to hold knowledge. *Conversation* is not a part of any participant; it is a connection between two of them, defined next. The *environment* is not a faculty at all; it is the participant that every action targets, the one whose replies are called observations.

**The three operations.** Participation is what happens when boundaries are connected, and three operations build all of it.

*Wiring.* To wire two boundaries is to connect them so that what one participant puts out arrives as what the other receives: one's outgoings become the other's incomings. Who is connected to whom is the entire content of a wiring. A conversation is a wiring of two participants. A tool call is a wiring of an agent to a tool. An action on the world is a wiring of an agent to the environment, and the environment's replies flowing back are feedback — a wire like any other, whose target is a neighbour. An agent connected to the world, its tools, a sub-agent and a human is one wiring diagram with five boxes.

*Iterating.* To iterate is to repeat steps while carrying state from one step to the next. A run, a dialogue, a control loop and a schedule of follow-ups are all iterations. Writing the steps out in order gives the transcript, the log. When repeating stops changing anything the system has converged; the converged state is a fixed point, and a repair pass that finds nothing to repair is the working test for it.

*Wrapping.* To wrap is to place one participant inside another's boundary so that it sees every step passing through and may pass it, alter it, deny it, escalate it to someone else, or merely record it. A gate, a reviewer, a verifier, a log, a canary and a rate limiter are all wraps. From the far side of the boundary nothing looks different — a denial looks like an ordinary failure — which is why wraps can be inserted anywhere without changing what is upstream, and why several can be stacked.

**The second level: re-wiring.** Everything above acts on the world. Above it sits a level that acts on the wiring itself: deciding which kinds of work may run without a human, resetting that trust when a model changes, rolling a model back, replacing a check whose blind spots have been learned. These change wires and wraps, not the world; call them re-wirings (the 2-morphisms of the precise form). Delegation is the bridge between the levels: when a participant hands work to a new agent it performs an ordinary step whose effect is a new wire. That is why delegation is kept distinct from action, and why it is the hardest thing to govern.

**Kinds of participants.** Humans, agents, tools and the world are the same kind of thing — occupants of boundaries. Since nothing is knowable about an occupant except through its boundary, they can be told apart only by what can be measured there: how fast it answers (latency), how much it can handle (bandwidth), how often it is wrong, how it degrades under load or persuasion. Call this the participant's datasheet. Four classes cover what is needed. *Environment*: answers, has no intent. *Tool*: a dependable channel into the environment. *Agent*: fast, broad, opaque, and — critically — adapts to whatever check it is wired to. *Human*: slow, low-bandwidth, saturates under load, decays fastest under persuasion.

**Slots and authority.** A wiring diagram has slots — proposer, reviewer, approver, author — and participants fill them. The same human fills different slots at different hours; an AI can fill a slot a human used to fill. Authority appears on no datasheet because it is not a property of an occupant: it belongs to the slot where a chain of review ends. A human reviewer is authoritative because the chain is wired to stop there, not because the human is more accurate. Authority is positional; accuracy is measured.

**Governance.** "May this happen?" is answered in two halves that must be kept apart. The interior half is regulation: the participant's own decision to act, hold back, escalate or warn. The exterior half is a wrap: a check that does not take the participant's word for it, because a participant's report about itself is just another outgoing it puts out. One law cannot be engineered away: once a wrap decides consequences, the regulation wired to it changes toward passing the wrap rather than toward being right. This is why boundaries compose exactly — a wiring of boundaries behaves as its parts predict — while the occupants inside them do not, since each occupant's behaviour depends on what it is wired to. Everything hard about governing agents lives in that gap, and it is why checks must be renewed rather than installed once.

**Recovering the lists.** Conversation, comprehension, retrieval: a wire, the inward map, an inward step. Intelligence equals knowledge plus regulation: the interior of a participant. Action, environment, delegation: the outward map, its target, and the step that creates wiring. Run loop: iterate. Agent action: a step from an agent to the environment. Human action: the same step from a human. Agent-to-agent conversation: an iterated wire between two agents. Agent-to-human conversation: the same wire with a human in one slot — same shape, different datasheet.

### 3. Examples

**A clinic.** A patient walks in. The consultation is a boundary: the doctor's outgoings are questions, prescriptions and referrals; the incomings are the patient's answers and, later, how the body responds. Each question-and-answer is a step. The patient describes symptoms and the doctor takes it in — comprehension. The doctor pulls the file — retrieval, a step whose counterparty is the records system, a store. Training and experience are the doctor's knowledge. The decision — treat now, wait and watch, refer, or say "I am not sure" — is regulation. Writing a prescription is an action; the body and the pharmacy are the environment, and the body's response is the observation that comes back. A referral is a delegation: the doctor has created a new connection and handed the case to a specialist, which is why a referral is a different kind of thing from a prescription. The whole appointment is a conversation: a wire between two participants. The series of follow-ups is an iteration, and the patient is "stable" when a follow-up changes nothing — convergence. The pharmacist who double-checks every prescription is a wrap: from the patient's side the doctor's boundary looks the same, but something now inspects every order. The medical board deciding which drugs need a second signature performs a re-wiring: it changes the wrap, not any patient. "Doctor", "pharmacist" and "specialist" are slots: an AI triage assistant can fill the doctor's slot for simple cases — same boundary, different datasheet: faster, never tired, more opaque, with no authority of its own, because authority sits with whichever slot the clinic's rules say has the final word.

**A coding agent.** A ticket arrives and the agent reads it — comprehension. It searches the repository — retrieval, a step against a store. It knows the language and the codebase — knowledge. It decides to proceed, to ask, or to stop — regulation. Editing files is action; the repository and the test pipeline are the environment, and test results are the observations. Spawning a sub-agent to run the tests is delegation: a new wire. The chat with the engineer is an agent-to-human wire. The agent's run loop is iteration; its log is the transcript; the task is done when another pass changes nothing. Pull-request review is a wrap. The team's rule that documentation changes may merge without review is a re-wiring. The engineer fills the reviewer slot; the agent could not fill it even if it were more accurate, because the authority belongs to the slot.

**The Law.** A student (regulation) learns what the examiner (wrap) rewards, and starts writing answers that pass instead of answers that are right. The only checks that do not teach this are the ones that run the test instead of grading the write-up — which is why the test pipeline above is a stronger wrap than the review.
