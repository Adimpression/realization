# Probability Relations 01 — Additive Combination

This document teaches one reusable arithmetic substrate and then reuses it in later probability relations.

The point is not only to store separate formulas, but to preserve the reusable semantic relation between the substrate operation and the later determinate relations.

## 1. Reusable substrate

When one quantity is obtained by adding two named input quantities, the reusable family is additive combination.

The reusable formula is:

$$ T = x + y $$

Where:

* input: `x`
* input: `y`
* output: `T`

This family should be reused when a later relation says that a total quantity equals one part plus another part.

## 2. Event count from disjoint parts

When two event groups do not overlap, the total count is an additive-combination relation.

The reusable formula is:

$$ N = a + b $$

Where:

* input: `a`
* input: `b`
* output: `N`

This relation reuses the earlier additive-combination family with event-specific quantities.

## 3. Distinguishing the relation

The formula is structurally simple, but its meaning depends on the claim that the parts are separate contributions to one total.

* additive combination is about composition into a total
* it should not be confused with multiplication, which scales or combines factors

If a prompt asks for total count from separate parts, use the additive family rather than a multiplicative one.

## 4. One-sentence summary

Additive combination is a reusable substrate for forming totals from separate parts, and later probability relations will reuse this when totals are built from component counts.
