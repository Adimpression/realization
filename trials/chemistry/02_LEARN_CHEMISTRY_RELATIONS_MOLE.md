# Chemistry Relations 02 — Mole as Counting Conversion

This document teaches one reusable counting-conversion substrate and then reuses it in later chemistry lessons.

The point is not only to store a formula, but to preserve the reusable semantic relation between counted entities and amount of substance.

## 1. Reusable substrate

When a total count is obtained by multiplying the number of groups by the count per group, the reusable family is grouped counting.

The reusable formula is:

$$ C = G * c_g $$

Where:

* input: `G`
* input: `c_g`
* output: `C`

This family should be reused when a later chemistry law says that a counted collection is built from equal groups.

## 2. Particles from moles

Chemistry uses the mole as a grouped-counting law.

The reusable formula is:

$$ N = n * N_A $$

Where:

* input: `n`
* input: `N_A`
* output: `N`

This relation reuses the earlier grouped-counting family with chemistry-specific quantities.

## 3. Moles from particles

The inverse use of the same relation is:

$$ n = \frac{N}{N_A} $$

Where:

* input: `N`
* input: `N_A`
* output: `n`

This relation reuses the same semantic structure, but now solves for number of groups instead of total count.

## 4. Connection to the previous lesson

The mole relation helps express atom conservation more usefully.

If atoms are conserved across a reaction, then corresponding mole amounts are also constrained by fixed counting relations.

So counting conversion can sit beneath balancing and stoichiometry.

## 5. One-sentence summary

Grouped counting is the broader reusable substrate; the mole law is a narrower determinate chemistry law that uses groups of size Avogadro's number to connect particle count and amount of substance.
