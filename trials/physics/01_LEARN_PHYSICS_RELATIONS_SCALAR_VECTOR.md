# Physics Relations — Scalars and Vectors

This document teaches one reusable representational substrate and then reuses it in later physics relations.

The point is not only to store separate formulas, but to preserve the reusable semantic relation between a quantity with only magnitude and a quantity with both magnitude and direction.

## 1. Reusable substrate

A physical quantity can either be treated as magnitude-only or as magnitude-with-direction.

The reusable relation is:

$$ Q = (	ext{magnitude}, 	ext{direction?}) $$

Where:

* input: `magnitude`
* optional input: `direction`
* output: `Q`

If direction is absent, the quantity is scalar. If direction is present, the quantity is vector.

## 2. Distance and displacement

Distance is a scalar description of change in position, while displacement is a vector description of change in position.

The reusable representations are:

$$ d = 	ext{magnitude only} $$

$$ \Delta x = (	ext{magnitude}, 	ext{direction}) $$

Where:

* `d` is scalar
* `\Delta x` is vector

This reuses the earlier scalar-vector substrate.

## 3. Speed and velocity

Speed is scalar, while velocity is vector.

The reusable representations are:

$$ 	ext{speed} = 	ext{magnitude only} $$

$$ v = (	ext{magnitude}, 	ext{direction}) $$

This again reuses the same substrate.

## 4. Distinguishing the laws

Distance is not displacement, and speed is not velocity.

* scalar relations do not preserve direction
* vector relations preserve direction

If a prompt asks for direction-sensitive motion, prefer the vector form.

## 5. One-sentence summary

Scalar-versus-vector is a reusable representational substrate that later motion laws reuse when direction matters.
