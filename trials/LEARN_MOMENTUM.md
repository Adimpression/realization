# Momentum

Momentum is a quantity that combines how much matter an object has with how fast it is moving.

For the scalar cases in this document, momentum is found from mass and velocity.

---

## 1. Core meaning

We will use:

* `m` = mass
* `v` = velocity
* `p` = momentum

For this scalar calculation:

* `velocity` and `speed` can be used as the same input value for `v`
* `momentum` and `linear momentum` can be used as the same output idea for `p`

Useful natural-language aliases:

* momentum
* linear momentum
* amount of motion
* mass
* velocity
* speed

---

## 2. Core equation

The reusable rule is:

$$
p = m * v
$$

This means:

* multiply mass by velocity
* the result is momentum

---

## 3. Reusable calculation form

Inputs:

* `m`: mass
* `v`: velocity

Output:

* `p`: momentum

If mass is in kilograms and velocity is in metres per second, momentum is in kilogram metres per second.

---

## 4. Worked examples

If:

* `m = 3`
* `v = 4`

Then:

$$
p = 3 * 4 = 12
$$

So the momentum is `12`.

If:

* `m = 5`
* `v = 2`

Then:

$$
p = 5 * 2 = 10
$$

So the momentum is `10`.

---

## 5. Natural-language paraphrases of the same task

These all ask for the same reusable calculation:

* calculate momentum from mass and velocity
* find momentum if mass and velocity are known
* what is the momentum when mass is 7 and velocity is 6
* compute linear momentum for a body with mass 8 and speed 9

---

## 6. One-sentence summary

Momentum is the product of mass and velocity.
