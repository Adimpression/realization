# Relationship between number of particles and moles

Formula: N = n × N_A

Where:
- N: number of particles (atoms or molecules)
- n: amount of substance in moles (mol)
- N_A: Avogadro's number ≈ 6.02214076 × 10^23 mol⁻¹

Alternative form: n = N / N_A

Key idea: one mole contains exactly N_A particles.

Example: If n = 3.50 mol, then N = 3.50 × 6.02214076 × 10^23 ≈ 2.11 × 10^24 particles.
